# ОСиАК — Лабораторная работа №2

Лабораторная работа по дисциплине «Операционные системы и архитектура компьютера».

Вариант 13.

Работа выполнена для Linux.

## Задание

Родительский процесс создаёт два дочерних процесса и принимает строки произвольной длины.

- child1 переводит строку в нижний регистр;
- child2 заменяет пробельные символы на _;
- результат возвращается родительскому процессу и выводится в стандартный поток вывода.

## Сборка

В папке inc:

```bash
make
```

## Запуск

В папке inc:

```bash
./build/parent
```
